# Rainfall Analysis and Planting Advisory

- This project cleans rainfall data for five Kenyan counties, uses NumPy to analyse rainfall patterns, and produces an SMS-oriented planting advisory.
- To run the analysis, install the packages in `requirements.txt`, open `rainfall_analysis.ipynb` in Jupyter, and run all cells from top to bottom.
- The analysis recommends April-May planting for Nairobi, Nakuru, Kisumu, and Mombasa, and November-December for Machakos, subject to current forecasts and the documented Machakos data-quality limitation.
